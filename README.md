# Sujjs Legacy

A tech and magic modpack for **Minecraft 1.21.1** on **NeoForge**, made by **SujjsTeam**.

Build your way through Create, Mekanism, Modern Industrialization, Ars Nouveau, Mystical Agriculture, Draconic Evolution and many more, all tied together by custom recipes, quests and the final goal: forging **The Absolute** in the Absolute Reactor.

## Download

| Where | How |
|---|---|
| CurseForge App | Search for **Sujjs Legacy** and click Install |
| GitHub | Download the latest file from [Releases](https://github.com/SujjsTeam/SujjsLegacy/releases) and import it in the CurseForge App (Create Custom Profile > Import) |

This repository only holds the pack's own files (configs, scripts and quests). It does not contain the mods. Always install the pack through one of the options above.

## Features

- **Absolute Reactor:** a giant multiblock built with Modular Machinery Reborn. While it forges The Absolute, its four towers fire lasers into the central tower.
- **Harder Modular Machinery:** every hatch and casing is made in machines from other mods, with a tier upgrade for each size.
- **Quests:** FTB Quests guide you from the first tools to the endgame.
- **Gem Drill and Chaos Drill:** Silent Gems and Silent Gear ores do not generate in the world. Mine them with these drills in the Modern Industrialization Quarry.
- **Unified ores:** Sujjs's Ores provides the common ores, and duplicate ores from other mods were removed.
- **Homes:** works in singleplayer and multiplayer, no cheats needed. Every player has their own homes.
- **Crash help:** when the game crashes, Crash Assistant shows what went wrong and helps you report it here.

## Commands

| Command | What it does |
|---|---|
| `/sethome <name>` | Saves a home where you are standing |
| `/home` | Lists your homes |
| `/home <name>` | Teleports to a home after 5 seconds. Moving cancels it |
| `/delhome <name>` | Deletes a home |

## Playing with friends

The host opens the world to LAN (Esc > Open to LAN). Friends on the same network, or connected through a virtual LAN like Radmin VPN, join with the host's IP and the port shown in the chat. Everyone needs the same version of the pack.

## Reporting a bug

1. Check [MOD_ISSUES.md](MOD_ISSUES.md) first. It lists known problems.
2. Open a [new issue](https://github.com/SujjsTeam/SujjsLegacy/issues/new/choose) and pick the right template.
3. If the game crashed, use the Crash Assistant window: it uploads your logs and copies the message you paste into the issue.
